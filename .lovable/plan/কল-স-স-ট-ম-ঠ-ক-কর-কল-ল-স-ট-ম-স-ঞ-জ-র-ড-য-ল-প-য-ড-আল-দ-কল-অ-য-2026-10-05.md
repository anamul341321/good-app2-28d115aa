# কল সিস্টেম ঠিক করা + কল লিস্ট + মেসেঞ্জারে ডায়াল প্যাড + আলাদা কল অ্যাপ

## ১. কল দিলে বোঝা যাবে
- কল দিলে স্ক্রিনে বড় করে লেখা থাকবে: "কল যাচ্ছে…" → "রিং হচ্ছে…" → "কথা চলছে 00:12"।
- রিং হওয়ার সময় যে কল দিয়েছে তার ফোনে "টুট-টুট" রিং শব্দ বাজবে।
- কল ধরলে ছোট একটা শব্দ + ভাইব্রেশন, আর সময় গোনা শুরু হবে।
- কেউ না ধরলে / কেটে দিলে পরিষ্কার লেখা: "ধরেনি" / "কেটে দিয়েছে"।

## ২. কল কাটার বোতাম
- কল যাওয়ার মুহূর্ত থেকেই নিচে বড় লাল "কল কাটুন" বোতাম থাকবে (এখন ডায়াল প্যাডে নেই — এটাই সমস্যা)।
- যে কাটুক, দুই দিকেই কল সাথে সাথে বন্ধ হবে।

## ৩. রিসেন্ট কল লিস্ট ও সেভ করা নম্বর
- কল সেন্টারে দুইটা ট্যাব: "ডায়াল প্যাড", "রিসেন্ট", "সেভ করা"।
- রিসেন্টে দেখাবে: নাম, UID, কল গেছে/এসেছে/মিস, কত মিনিট কথা হয়েছে, কবে। ট্যাপ করলেই আবার কল।
- যেকোনো UID নাম দিয়ে সেভ করা যাবে (ফোনের কন্টাক্টের মতো), মুছেও ফেলা যাবে।

## ৪. মেসেঞ্জারে কল
- মেসেঞ্জারের ওপরে "কল" বোতাম — চাপলে একই ডায়াল প্যাড, রিসেন্ট ও সেভ করা নম্বর খুলবে।

## ৫. আলাদা কল অ্যাপ (Good-App Messenger APK)
- শুধু মেসেঞ্জার + কল + ডায়াল প্যাড থাকবে, ভারী জিনিস (Reels, মাইনিং, ওয়ালেট) থাকবে না — তাই খুব হালকা ও দ্রুত।
- কল এলে ফোনের নিজস্ব কল স্ক্রিন আসবে, "রিসিভ" চাপলে লোডিং/অ্যানিমেশন ছাড়াই সরাসরি কথা শুরু।
- একই একাউন্ট দিয়ে লগইন; মূল অ্যাপের সাথে চ্যাট/কল একই থাকবে।
- GitHub থেকে আলাদা APK তৈরি হবে, অ্যাডমিন প্যানেল থেকে আপলোড করে ডাউনলোড লিংক দেওয়া যাবে।

## Technical details
- `call_sessions` থেকে recent list (accepted_at/ended_at দিয়ে duration); নতুন `call_contacts` টেবিল (owner_id, peer_id, label) RLS self-only।
- `CallProvider` আউটগোয়িং স্টেট overlay সবসময় hangup দেখাবে; ringback tone `ringtone.ts`-এ।
- Calls UI কে shared component করে `/callcenter` ও messenger route দুটোতেই ব্যবহার।
- আলাদা APK: নতুন Android flavor `messenger` (ভিন্ন applicationId, start URL `/chat`, splash বন্ধ), workflow-এ আলাদা build job; IncomingCallActivity answer হলে সরাসরি call route খুলবে।
- সতর্কতা: আলাদা APK চালাতে আলাদা Firebase app (google-services.json) লাগতে পারে।
